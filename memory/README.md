# Memory System

ArguMind uses a two-layer memory architecture.

## Episodic Memory

Stores completed debate sessions.

Each debate contains:

- Topic
- Stances
- Winner
- Scores
- Reflection
- Fallacies

## Semantic Memory

Stores long-term user characteristics.

Examples:

- Strengths
- Weaknesses
- Favorite topics
- Favorite personas
- Average debate scores

This memory evolves after every debate.
